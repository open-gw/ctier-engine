# 12c — consume 1.2.0, supersede ADR-006, close the cycle

## The promoted schemas were not byte-identical to the drafts

They differed. The differences are the promotion ceremony 12b named, not a
change to required fields, enums, or case shape. Switching was the rest of
this task; recording the diff is the point of having compared first.

| What changed | What did not |
|---|---|
| `$id` and title: engine draft path → `open-gw/ctier/spec/schemas/…` | required arrays |
| `description`: 1.0.0 is when an implementation *other than the reference one* has been held to the format | enums (`disposition`, `escalationReason`, `profile`, `deployment`) |
| `ctierSchema` const: drop `-draft`; `ledger-decision` → `decision-record` (same for attempt and outcome); corpus `0.3.0-draft` → `0.3.0` | object shape of a case, a Decision, an Attempt, an Outcome |
| `composition`: inline `pattern` → `$ref` to `ctier-extensions-0.1.0.json#/$defs/digest` | the pattern itself (`^sha256:[0-9a-f]{64}$`) |

The `$ref` is why `validate_record` now goes through `validate_named_schema`
and the vendored registry. A bare `Draft202012Validator(schema)` cannot
resolve the digest without fetching, and fetching is forbidden.

Old `ledger-*` names still parse at custody ingress so a leftover fallback
line is not a 400. New writes stamp `decision-record/0.1.0` and kin.
`ctier/spec/draft/` is gone. The drift manifest covers the four files with
every other schema.

## The safe direction and the dangerous direction are not symmetric

This is the third instance of the same shape, not three coincidences.

1. **Overlay single-target.** An overlay may select many operations only
   when assigning Tier 4. Lowering many at once is the dangerous direction
   and is forbidden by construction.
2. **C3 unidirectionality.** Escalation may only raise. A runtime input
   that would produce a tier below the declared floor is discarded, not
   averaged, not "corrected."
3. **Migration evidence.** A proposal to *lower* a tier requires a
   strictly larger minimum sample, a strictly longer window, and zero
   contrary events. A proposal to raise does not. Three data points do
   not become a recommendation by being labelled tentative: below the
   minimum, nothing is emitted.

In a governance system the two directions are not alike, and a mechanism
that treats them alike is wrong by construction. The attack this bar
exists to make expensive: approve a Tier 3 operation until the system
proposes Tier 2, then have anything apply that proposal, and thereafter
the operation executes with no review at all. The governance system would
have been walked down by its own evidence.

So the output is a document. There is no apply path, no flag, no trusted
mode, no confirmation prompt in a pipeline. Changing a tier remains a
declaration in the interface description.

## What the live ledger is enough to propose

Nothing. Ran `propose_migrations` over a ledger sized like the live
suite: a handful of Tier 1 executes, one Tier 3 withhold with an executed
Outcome, a Tier 4 in-window, an Attempt. Production defaults (raise ≥ 10
in 14 days; lower ≥ 50 in 90 days, zero contrary). Empty `proposals`.

That is honest. The live suite was never going to accumulate fifty
clean approvals of the same operation, or ten bounds escalations, or a
Tier 4 that exists in history and is absent from a two-week window. A
cycle edge that has never had enough evidence to propose anything is
what M6's demo will need to manufacture deliberately.

C8 rejection is still not a ledger type. `decide(reject)` mutates the
pending SQLite row and writes nothing the proposal engine can see. The
Tier 3 → Tier 4 signal therefore joins **failed Outcomes** to a withhold.
Until rejection is ledgered, live data will not fire that signal even
with a large sample of declined work. That is a gap in the evidence, not
in the proposal rule.

## NEW-MATTER

The provisional does not name a cycle edge that **cannot apply its own
output**, nor the asymmetric bar that makes lowering expensive on
purpose. ADR-0011's unavailable floor (identity, not denial) was named
in 12a; this file does not rename it.
