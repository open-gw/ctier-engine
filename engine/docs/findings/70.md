# 70 — the last four, then v1.0.0

Date: 21 September 2026. Public tree. Spec read only.
Did not deposit Zenodo. Did not force-push.

Seventy tasks. Sixteen criteria, three of which had never been
written down. A conformance kit whose first failure was its own.
Two engines that agree because something checks, not because one
person read two reports. Seventy-four restatements removed from
an implementation that had quietly become a second edition of its
own specification.

**None of it was found by the system breaking.** It was found by
asking what a name meant, what a rule permitted, and whether
anyone had ever looked.

What the chain cannot show is whether any of it works for someone
else. Two things are parked on that and neither can be closed from
here: **a stranger following the Kong instructions, and an Apigee
org producing a result file.** Until one of those arrives,
everything in this repository is a well-checked claim by its
author.

That is a good position to be in and it is not the same as being
verified. The release notes say so in those words.
