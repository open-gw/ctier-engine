# 13e — record the mechanism, and make the topology unambiguous

13c changed how delegation-chain integrity is enforced. This
repository now records that as ADR-0012. Spec 1.3.0 is vendored;
SHA256SUMS is unchanged, which is what 13d's Part 4 predicted.

## Part 4 — the digest does not cover agent identities

The composition digest is `sha256` of the canonical JSON of the
**qualified OpenAPI document**. Agent identity declarations live in
`authorization.yaml`, emitted by `generate()`, not by `compose()`.
They are outside the digest.

Two deployments of the same API with different agent topologies
share a digest. `test_composition_digest_does_not_cover_agent_identities`
holds that. Reconstruction of the chain from a decision record
(actor + digest → deployment → topology) is therefore ambiguous —
the same defect Part 3 removes from a single deployment, reintroduced
one level up.

The task said to stop and report. The remedy is probably to bring
the declarations inside the digest. That changes what the digest
means (C13 binds assignment to the composed interface description)
and is not a decision this task takes. No reconstruction procedure
is written. No new record field. No mapper.

## Shared sub-agents did not occur naturally

Rejecting an identity under two parents made **no** existing example
or test fixture invalid. The reference generate is a tree of depth
two (`agent-a` → `agent-sub-balance`). Goldens gained a `parent`
field on that one client; nothing had declared the same child twice.
The shape does not occur in this repository's fixtures. The error
message will be read the first time someone writes it, not every
time someone regenerates.

## Three compiled absences

This is the third correctness property in the system implemented as
a compiled absence rather than a runtime check:

1. **Exclusion** — the scope is never granted.
2. **Suspension** — the scope is removed.
3. **Delegation** — the identity was never entitled.

Whether that is a coincidence of what gateways and authorisation
servers happen to make configurable, or a property of governance
mechanisms generally, is not answerable from three instances. The
three are named together here before they are described separately
in ADR-003 (the first two) and ADR-0012 (the third).

## NEW-MATTER

None from this task. Entitlement-bounded exchange was 13c's. The
digest gap is a measurement of C13's current input, not a mechanism.
The one-parent rule is a generate-time uniqueness constraint on a
declared topology.
