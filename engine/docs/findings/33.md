## Observation

This project has been careful to record numbers as measured rather than
estimated. It has been less careful about saying **which kind of number** each
one is, and the two failure modes are different: an estimate presented as a
measurement is dishonest, whereas a sample presented as a bound is merely
ambiguous — until someone reproduces it on different hardware and concludes the
implementation changed.

The convention costs one column and removes a class of argument that would
otherwise happen in public.
