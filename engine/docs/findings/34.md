# 34 — a demonstration a stranger can run, and an Apigee package they can verify

Date: 18 September 2026. Requires 32 and 33. Did not edit the spec.

## The question this task is the first to face

Everything until now has been verified by tests the author wrote and ran. This
is the first artefact whose audience is someone with no context, no stake, and
no patience. The failure mode is not a red test. It is a reader who runs it,
sees output, and cannot tell what was proved.

That forced the beats to print three lines each — doing, expects, evidence —
and to refuse pytest as the entry point. A passing suite tells a reader the
author believes it works. The demo has to show a ledger row, a log line, a
status, a token claim.

## What had to be rewritten to be legible

- **Beat 6** was the live accumulation test almost verbatim. The test asserted
  a bound. The demonstration had to *say* the bound is Derived (one poll
  interval) and that the 216 ms APISIX sample is not it. Leaving that as an
  assertion would have been the same lie 33 exists to prevent, just spoken
  to a stranger.
- **Beat 10** had no live counterpart that fired a migration signal. The suite
  never produced a population. Seeding by INSERT would have been the worst
  thing this project could ship. The beat POSTs through `/v1/ledger` and
  announces, in its own output, that the calendar is synthetic and the
  objects are not.
- **Sameness** is not “it works on two gateways”. The composition digest is
  printed once per engine and compared. Remaining differences are named:
  APISIX stock OIDC vs Kong Lua (403 vs 401 after revoke); APISIX T4 is
  fault-injection and does not revoke (Kong T4 does); APISIX has no Attempt
  JSONL fallback; poller hook. Hiding any of those would have been a
  demonstration that matched by omission.
- **Reset** is the first thing the command prints. A second run that differed
  because suspension persisted would have been a demonstration that lied
  about reproducibility.

## Apigee package

`targets/apigee/package/` is what a person with an organisation acts on:
generated bundle, deploy instructions, verification claims, harness,
report-back template. It states what is unproven: no local runtime, `print()`
is Trace, precedence untestable.

The template asks for the differential report, the disagreed cases, strip
evidence, withhold evidence if custody was wired, and the org's FlowHooks /
shared flows — not a sentence that it seemed to work.

## Observation

The gap between a test that passes and a demonstration that convinces is
mostly *what is said while it happens*. The machinery was already there. The
work was refusing to let a 202 sit without a pending row, refusing to let
decomposition sit without naming the bound's kind, and refusing to let Beat 10
close the cycle on evidence nobody was told was manufactured.
