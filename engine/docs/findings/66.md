## What was built

### Backend observer

`targets/apigee/package/observer/` —
same echo contract as Kong/APISIX live
(`GET /_harness/requests`). Tester aims
the proxy target and sets
`kit_observer`. Not a mock gateway.

### Retrievable records

- Generate: optional `records={"url"}`
  compiles fail-open
  `SC-RecordDecision` on execute and
  refuse paths; Trace `print()` stays.
- Stock `build.sh` / demo compile
  `https://records.example.invalid`.
- `targets/apigee/package/collector/` —
  `GET/POST /v1/ledger` →
  `{ "records": [ … ] }`. **Not
  custody** (no pending, no approve).

Records **can** be made retrievable on
Apigee: not via Trace, via an HTTP
collector the Message Processor can
POST to. Declaring Trace a sink would
have been a lie.

### Not built (unlock 0 or forbidden)

Runner wheel, Management API deploy,
OAuth product wiring, local Apigee
emulator, mock custody stand-in.

## Three honest outcomes — which one

**Ports partially; the observability
map gains an Apigee-shaped note.**

Not "package was merely incomplete and
now equals Kong." Not "criteria are
unobservable on any managed gateway"
for C10/C16 — those become observable
when the collector and observer are
wired. What remains unobservable or
untestable from this artefact:

- Local runtime parity
- C11 vs PreProxy FlowHook
- L3 without a **real** custody the
  tester supplies
- Pass/fail proof without an org

**Reviewer sentence:** Some kit rows
need a GET surface Apigee Trace does
not provide; that is a packaging and
target-column fact, not proof the
framework cannot reach a managed
gateway — and not proof it already does
until someone runs the checklist on an
org.

---

## Recommendation

Is the Apigee claim worth making with
what now runs?

**A cautious, partial yes — as a
provisioned kit column, not as parity.**
With observer + collector wired, Level
2 can exercise status cases plus C10
and C16. That is enough to start an
Apigee column next to Kong/APISIX, and
not enough to claim the same live
matrix. Without an org result file,
do not publish "Apigee passes."
