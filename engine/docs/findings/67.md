history rewritten. No licence chosen.

A publish decision changes the reader.
Everything in this repository was
written on the assumption that the
reader knew the project. Going public
replaces that reader with someone who
forms their entire judgement from what
is on the page, in about four minutes,
and will not ask.

The repository does not need to be more
impressive for that reader. It needs to
be **harder to misread** — saying what
is not true yet before someone assumes
it is.

Going public exposes **the whole
history**, not the current tree.

## Part 3 — Licensing

### Engine code licence — options, not a choice

The published specification (`open-gw/ctier`)
is **CC BY 4.0** — a document licence.
It is not a software licence and grants
no patent rights.

**This task does not choose a licence.**
Note: the tree already contains
`LICENSE` (Apache-2.0 text), `NOTICE`,
and `LICENSING.md` asserting Apache-2.0
from earlier work. That assertion is
**not ratified** here. Options for the
author:

| Option | What it gives adopters | Implications |
|---|---|---|
| **Apache-2.0** | Use, modify, distribute; express patent grant from contributors for the Work | Matches current `LICENSE`/`NOTICE` files if retained. Patent grant is for the Work, not for provisional 64/137,066 in the abstract (already footnoted in NOTICE). |
| **MIT** | Maximal simplicity; use/modify/distribute with notice | No express patent grant. Adopters who care about patents read the provisional note and ask counsel. |
| **BSD-3-Clause** | Similar to MIT; no endorsement clause friction for some orgs | Same patent gap as MIT. |
| **MPL-2.0** | File-level weak copyleft | Modified MPL files must stay MPL; larger proprietary wrapping possible. More compliance process than MIT/Apache. |
| **GPL-3.0 / AGPL-3.0** | Strong copyleft | Adopters embedding the engine in proprietary gateways may refuse. AGPL additionally pressures network use. Awkward for a kit meant to be run against commercial gateways. |
| **All rights reserved / no licence** | Adopters have no grant | Incompatible with “people run the kit”. Do not publish in that state. |
| **Dual** (e.g. Apache-2.0 OR MIT) | Flexibility | Increases clarity work; still a choice that must be explicit. |

CC BY 4.0 on the **specification**
remains separate from whatever covers
engine source.
