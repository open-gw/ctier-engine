# 41 — both engines refuse an unassigned path the same way

Date: 19 September 2026. Requires 40 (spec 1.14.0). Did not edit the spec.

38 found the two live engines answering `/estate/unknown` in opposite
directions, and neither doing what C12 requires. Kong assigned Tier 4
via a global plugin. APISIX returned 200 and forged a header through
to the backend. This task separates the two cases 40 named.

| | Today (38) | After 41 |
|---|---|---|
| Kong | Tier 4 via a global plugin, stripped, classified, recorded | refused, recorded **undetermined** |
| APISIX | `200`, forged header at the backend, nothing recorded | refused, recorded **undetermined** |

## Part 1 — Kong

The global `ctier` instance still applies C2's undeclared default to
a route **in** the composition with no route-level instance
(`exportStatements`, 08c E3). It now also receives the governed set —
the operation names generate already knew — and refuses a matched
route that is not on that list as an Attempt (`appliedTier` null,
`reason=unassigned`). That is not a Decision with `appliedTier` 4.

The same list is written on `ctier-generate.json` as `governed`. An
operator can read which operations are covered without parsing the
deck. That is 40's discoverability obligation and the plugin's
membership test: one artefact, two requirements.

## Part 2 — APISIX

The generated `undeclared` route is still `/*` at priority 1. Raising
that number is not the fix. The catchall now refuses and records
undetermined for a path the composition does not contain. A
composed-but-unassigned path that reaches it (`exportStatements`)
stays C2: 423, `halt_and_hand_off`, no Attempt.

A more specific added route wins over `/*` at any priority. 38
measured 100; specificity is enough. That escape is stated in
`docs/portability.md`. It is the drift property 40 scoped C12
around, not a bug to be out-prioritised.

## Part 3 — The ledger distinguishes them

The record schema already could. No schema task.

| Fact | Record | `appliedTier` |
|---|---|---|
| A composed operation classified Tier 4, refused | `decision-record/0.2.0` | `4` |
| A path the composition did not contain, no assignment found | `attempt-record/0.2.0` | `null` |

C12's miss is the Attempt case validation.md already named. The
named Attempt remains custody-unavailable; `reason` separates the
two (`unassigned` vs `custody-unavailable`). `declaredTier` on an
Attempt is still a required integer — the plugin writes 4 because
the schema will not take null. That does not collapse the two facts:
a reader looking at record type and `appliedTier` can tell them
apart. A schema that allowed `declaredTier` null on an Attempt
would match "where known" more closely. That is a schema question;
it was not folded in.

## Part 4 — The runtime suite

`unknown-path-refused-undetermined` asserts all three: refused,
an undetermined Attempt, and **no Decision**. The third is what
Kong's old behaviour would have failed. Four cells: Kong fragment,
Kong bundle-drift, APISIX fragment, APISIX bundle-drift.

APISIX's add claims `/estate/drift-extra` so the catchall still
receives `/estate/unknown`. A route that claims the probed path
escapes; that cell is the bound, not the case.

## Part 5 — What this does not fix

A route added after generation can still escape, on both engines.
Kong: a route-level instance overrides the global plugin; a path
that matches no route is 404 and is not recorded. APISIX: a more
specific URI wins over `/*`. This task narrows the gap. It does
not close it.

## Observation

Kong passed every suite this project has while doing the wrong
thing, because the wrong thing produced a refusal and a ledger row.
The runtime suite checks what arrives; it did not check *which
record* arrived. A record of the right shape carrying the wrong
fact is the next failure mode after no record at all, and this is
the first time it has been caught.

## Spec author

`docs/NEW-MATTER.md` is not in this repository. For the spec author:

- Attempt `declaredTier` is a required integer 1–4. A path with no
  declared assignment cannot be recorded without inventing a number.
  validation.md says "the declared tier where known."
- C10 still says "operation" with no composed-description bound.
  40 already filed that. This task did not restate it.
