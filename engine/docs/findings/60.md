Date: 20 September 2026. Requires 59 (spec 1.25.0,
`ad6031b`). Engine origin/main was `547c8f7` (task 61).
Did not edit the spec. Did not push. Documentation only.

59 declined nine candidates. Eight existed only as
requirements in this repository's documents. 48 declined
"recorded before acted on" and left it stated here as
normative. 46 converted seventy-four restatements to
references; these remaining were invented — requirements
the specification does not make and as of 1.25.0 has
explicitly decided not to make.

Direction: every earlier correction moved one way —
something missing from the spec got written. This is the
first that **removes** requirements, from the
implementation rather than the specification. Seven
inventions, written in good faith, each would have
constrained a second implementation that read the wrong
document — exactly what happened to task 25's audit. An
implementation's documents are where a specification
grows without anyone deciding to grow it. 46 found that
direction of drift and this closes it.
