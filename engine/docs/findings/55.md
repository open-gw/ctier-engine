## Part 1 — does not apply, decided first

Generator refuse-to-emit. Rule `c13`. Both engines. Both
modes. The mismatch never reaches the gateway.

Not an enforcement-point refuse. The EP has only the
compiled assignment. A request does not carry a
composition. Same operations would be enacted if A's deck
were loaded under B's name.

They differed before the check. Fragment already refused
(`replace`, same route names). Bundle ignored `existing`
and emitted B. The C13 check makes the refuse the digest,
on both modes, before replace or replace-the-estate. An
estate fixture with no generate stamp is not this check.
