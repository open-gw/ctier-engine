against that version.

---

## What it is for

Two implementations agreed by a person
reading two reports. It does not extend
to a third target.

Apigee has been waiting on "how would
they know it worked?" The kit is that
answer. It is the first artefact in
this tree built to be run by someone
who does not already know what it
should say. URL and credentials. One
command. A result file. An instruction
sheet that does not use words they
would have to look up.

A bar the reference clears completely
the day it is written was written to
be cleared. The first Kong and APISIX
matrices include the failures.
