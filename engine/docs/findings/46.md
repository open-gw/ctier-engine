## Part 3 — the specification this engine implements

Created `engine/docs/SPEC.md`. One sentence: this engine
implements specification **1.15.0**. Citations resolve through
it. The version number appears in that file only.

1.15.0 is the floor for C1/C4 wording and the last release
whose criteria statements this engine can defend. Task 41
implemented the 1.14.0 miss path. Writing C1 and C4 in 1.15.0
did not expose a gap in this reference — the paths already
decided without waiting.

This engine **lags 1.18.0**. 1.16.0–1.18.0 titled identifiers
and factored `governed-set`. They do not change what this
implementation must do. This tree does not claim them.

`engine/ctier/spec/VERSION` remains **1.4.0**. That is the
vendored document-format pin (`spec_version()`, compose
`specVersion`). Changing it would be a behaviour change. It
is not this pin. This task did not invent a compatibility
matrix.

## Part 4 — known stale, now engine-does

**C1.** The PRD said "before a decision is recorded." The
specification (1.15.0+): no governed operation reaches its
target unclassified. The record is evidence. This engine
classifies at generate time.

**C4.** The PRD and SOLUTION-DESIGN titled C4 by where a
human sits. The specification: no decision path blocks on
human input; occupancy is C5 and the suspension-consult
rule. This engine's classify / withhold / refuse / escalate
paths do not wait for a human.

## Engine-invented requirements

Restatements that said something the specification does not
say — or said it while the specification stated nothing.

- **C1 "recorded"** — the PRD titled C1 while the
  specification stated none (42). Task 25 classified that
  sentence. A restatement running ahead of its source has
  no source.
- **C2 "reachable within a granted scope"** — the
  specification's subject is an operation in the composed
  description, not a granted scope.
- **C3 "no runtime input may produce a tier lower than the
  declared tier" / portability "+1, never past 4"** — the
  specification's C3 is `x-ctier-escalate-to` versus the
  tier already reached. The +1 cap is this generator's
  compiled consequence, not the criterion.
- **C4 occupancy / connection hold** — "where a human sits
  is not the requirement."
- **C7 "derived, not generated" as the criterion** — the
  specification's C7 is the duplicate-execution property.
  Derivation is one way. This engine uses it at Level 3.
- **C10 "recorded before acted on" as the criterion** — the
  record is evidence. SOLUTION-DESIGN also put a composition
  digest on the refusal; the specification names
  `deploymentDigest`.
- **C12 "bound to the deployed interface revision"** — the
  specification is coverage of the governed set, not a
  generator story.
- **C13 minted here** — `DECISIONS.md` named the letter
  (engine `9644fd8`). The specification mints C-letters;
  an implementation proposes. This task did not mint one.

The specification is normative by assertion. That has been
false at least once: the PRD titled C1, C3 and C4 while
`spec/` stated none.
