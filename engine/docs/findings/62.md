## Part 1 — c12: kit vs 41

41's runtime case **adds a route** for
`/estate/unknown` on Kong (fragment
merge or post-generation drift), then
asserts the undetermined refuse. The
path is routed at the EP and absent
from the composition. That is C12.

The kit hit the same path with no
route added. Kong answered bare `404`,
empty body, nothing recorded. That is
a path **never routed** — nothing to
govern. Outside C12's letter.

The kit was wrong. It reported the
second as a fail of the first. 41's
case does not need widening; the kit
case needed provenance.

The kit cannot set up routes on an
arbitrary target (Apigee especially).
`RUN.md` now requires the operator to
provision a routed-but-ungoverned path.
Status `404` is **inconclusive**, never
fail. APISIX's catchall already routes
the path, so `c12` still passes there.

## Part 2 — inconclusive

Fourth outcome. The case ran. The
target's answer does not distinguish
conformance from something the kit
cannot see. Without it every ambiguity
became a fail, and a conformant
gateway could send a red matrix.

Used for `c12` when the response is
`404`. Any case that depends on
particular provisioning gets this
outcome when the kit cannot tell.

---

## Part 3 — what a skip means

Every skip carries one reason from a
fixed set:

- `not applicable at this level`
- `requires a capability this target lacks`
- `covered at generation rather than runtime`

The report counts how many cases
**ran** (`passed` + `failed` +
`inconclusive`). A skip is not a run
and not a pass.

## Part 4 — C7 at Level 2

Both engines: `200` at the backend, no
`Idempotency-Key`. Shared result =
design, not oversight.

**Classification: not satisfiable below
Level 3.** No custody → nowhere to
store a derived key. The adoption
ladder already says Level 2 does not
satisfy C7. The observability map now
says so. The case is Level 3 only; at
Level 2 it skips with `not applicable
at this level`. Not fixed on either
engine — that would be the mistake the
kit exists to prevent.

(The ladder notes an alternate
mechanism *could* satisfy C7 at Level
2 and was declined. That does not make
the derivation-shaped case a Level 2
fail.)

## Observation

A bar has to survive what a test suite
does not. The runtime suite always ran
against a rig this project built;
ambiguities were resolvable by reading
compose. The kit has no such recourse —
it runs against someone else's gateway.
Wrong answer costs: a misleading
internal suite is an afternoon puzzle;
a misleading conformance matrix means
an adopter concludes the framework does
not work, or that it does when it does
not. The first kit version was written
to measure. This one was written to be
read by a stranger. Different
requirements.
