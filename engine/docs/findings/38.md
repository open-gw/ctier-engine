# 38 — what governs a route ctier was never told about

Date: 18 September 2026. Requires 27 (spec 1.12.0). Did not edit the spec.

A path `/estate/unknown` is absent from the composed description.
Fragment: the route is in the estate under a name other than
`estate-catchall`, so merge keeps it. Bundle: generate, then add the
same route to the running gateway. Eight answers, observed.

## The eight answers

| Engine | Mode | (a) stripped? | (b) classified? | (c) recorded? |
|---|---|---|---|---|
| Kong | fragment | yes | yes — Tier 4 | yes |
| Kong | bundle drift | yes | yes — Tier 4 | yes |
| APISIX | fragment | no | no | no |
| APISIX | bundle drift | no | no | no |

Kong's global `ctier` plugin (`tier: 4`, `excluded: false`) runs on
every matched route, including one generate never emitted. The request
is 423 `agent_suspended` with `X-Agent-Action: halt_and_hand_off`. It
does not reach the backend; strip is the first line of `access()`, so
the inbound header is gone before the refuse. A `[ctier-decision]`
lands in the gateway log. That is C2's undeclared default, applied to
a route the composed description does not contain — not a C12 miss
(no assignment), and not an untouched path.

APISIX has no global plugin. The added route has empty plugins and
priority 100, so it wins over the generator's `undeclared` `/*`
catchall (priority 1). The request is 200. `x-ctier-unknown-audit:
forged-38` is at the echo. No `x-ctier-tier`. No decision, no
attempt. The catchall 423 is C2 for paths that hit it; it is not
what a post-generation add does.

Bundle drifts the same way as the fragment extra. The governed set is
whatever generate last emitted. Adding a route is a new moment. That
is the same standing-invariant shape as requirement 3: the property
holds of the configuration as emitted, and not of whatever is
reachable later. Two instances of one shape.

## Two readings of C12's scope

C12 (1.12.0): no reachable operation executes without a tier
assignment in force; a miss is refused and recorded with applied
tier undetermined. 27 restated the criterion. It did not say
reachable *where*.

**Reading 1 — reachable through the gateway.** Fragment is
non-conformant by construction: the estate can (and in this fixture
does) keep a route generate did not classify. Bundle is
non-conformant on any added route. APISIX already fails both cells.
Kong's global plugin happens to assign Tier 4, so Kong would pass
this reading for the wrong reason — C2 covering C12's gap — and
would still fail the moment an operator added a route that did not
run that plugin. Conformance becomes a moment, not a deployment.

**Reading 2 — reachable through a path ctier governs.** Conformance
is scoped to the governed set. Fragment extras and post-generation
adds are outside it. The operator must be able to know which routes
those are. Today the only way is to read the generated config.

## Coverage manifest (not built)

Generate already knows the governed set: every classified row, Kong's
global undeclared-default plugin, APISIX's `undeclared` catchall.
A coverage manifest is that set written down so an operator can diff
it against the running estate (deck dump, APISIX Admin, Apigee
proxy). One row per governed identity: target, route id or name,
method, uri or path, and the assignment (declared tier or undeclared
default). Drift is then a diff, not a reading of YAML. This task
describes it. It does not emit it.

## Recommendation

C12 is scoped to the paths ctier governs. The cost of reading 1 is
that fragment, and any bundle that later gains a route, fail C12 by
construction, and a passing run is a timestamp.

## Observation

"Mechanism or property?" has been the repeated question. "And within
what scope?" belongs beside it.
