# 12a — accumulated consequence as an out-of-band scope floor

ADR-006 says the enforcement point reads the scope floor locally and
**fails closed if it cannot**. Taken literally, an enforcement point with
no floor treats everything as Tier 4. That is a constant function. It
would be the third time in this project a fail-closed default collapsed
into one.

The property that is actually true, and the one this task built:

> Accumulation is a **heuristic escalation**, not an authorisation
> boundary. It can only raise a tier above the floor already compiled
> into the configuration. When the accumulated floor is unavailable, the
> compile-time floor still governs — and that floor is what a human
> declared as sufficient for this operation. Its absence therefore
> permits nothing that was not already permitted.

An unavailable scope floor means **no escalation, not maximum
escalation**. That is not fail-open in the dangerous sense. Nothing is
allowed that the declared tier did not already allow; only the additional
protection against decomposition is absent. Live: custody stopped
mid-sequence produces 200s at the compiled tier, never 423, never 503.
A superseding ADR follows in its own task. This file records the
correction; ADR-006 is left as the decision it was.

## The window

ADR-006 accepted one request late: the call that crosses the threshold
executes at the compiled tier. With a poller the true window is
**threshold-crossing plus up to one poll interval (1000 ms)**.
That 1000 ms is Derived from the configured interval, not Observed.
The Decision is written in `access`; the floor is visible after the next
successful `ngx.timer.every` tick. `docs/portability.md` states that
bound. The live test asserts it as a bound, not an exact request index.
`appliedTierAtLeast` exists so the corpus does not encode the interval.

`floor_poll_ms` is 1000. `custody_timeout_ms` is 200. Both are
Configured; the visibility bound (threshold-crossing plus one
interval) is Derived. Classified in [`measurements.md`](../measurements.md).

The live rig sets `CTIER_DECAY_SECONDS=5` so a gap longer than the
decay window is testable. Production default remains 1800. Findings
that quote a five-second decay are quoting the fixture.

## The ledger is no longer only observational

No new data path. Custody recomputes the floor from Decision records
already written for audit, using the same `Accumulator` the in-process
classifier uses (weights, `escalate_above=9`, decay). Attempts are not
replayed. Weight is taken from the **declared** tier, not the applied
tier after a floor raise: weighting the raised value would feed the
floor into itself and it would never recede.

A record written for one purpose is now load-bearing for another.
Changing retention, dropping `declaredTier`, or sampling the ledger
would change what the defence sees without changing what the auditor
thought they had agreed. That coupling is the sentence to have before
someone shortens the ledger to save disk.

Decision records have no `contributes_weight`. Per-operation
`x-ctier-weight` is unused. The published floor is 2 (escalate from
Tier 1). Empty `floors` is no escalation.

## What Kong does

The plugin does not call custody on the request path for the floor. It
reads `ngx.shared.ctier_floors`, populated by a background timer. GET
`/v1/floors` sits on that timer with the 200 ms custody timeout. A
missing dictionary, a missing key, or a failed poll is logged and the
compiled tier stands.

Single-request corpus cases stay valid as a sequence of one.
`conformance-corpus/0.3.0-draft`. Sequential live cases are Kong-only:
the reference adapter constructs a fresh `Classifier` per `run()`, so
it would escalate on the crossing request — a different mechanism, not
a disagreement.

## NEW-MATTER

Two things the provisional does not name, if they belong there:

1. Accumulated consequence as a **locally read, out-of-band, monotonically
   raising floor whose absence is identity** — not denial, not a hop, not
   an authorisation boundary. Fail-closed-to-4 is the reading that looks
   like security and is a constant function.
2. The **audit ledger as the accumulation input**. The defence runs on
   the record written for evidence. That is a coupling, not a second
   stream.

The shared-dictionary poller is how Kong encodes (1). It is not itself
the invention.
