# 52 — the engine consumes 0.3.0, and stops claiming a version

Date: 19 September 2026. Requires 1.21.0 (`b0e223b`). Independent
of spec 53. Did not edit the spec.

51 made `declaredTier` optional so an Attempt can say no
declaration was made. This engine still wrote `4`. `docs/SPEC.md`
still said this engine implements 1.15.0.

## Part 1 — stop writing a tier nobody declared

Vendored `attempt-record/0.3.0` from 1.21.0. Writers emit that
`ctierSchema`. `declaredTier` is present when a declaration was
made and omitted when none was. Do not write 4 to mean unknown.

Kong: `record_attempt(conf, nil, "unassigned")`. APISIX catchall:
no `declaredTier` field. Custody-unavailable still carries the
declared integer — a declaration was made.

`VERSION` stays **1.4.0**. The 0.2.0 schema stays so a reader can
name an old row. That pin is the document-format floor, not a
claim that every later record type is absent.

**Interim placeholder note.** None in `docs/portability.md` or
the living record docs. The only note is historical:
`docs/findings/41.md` — the plugin wrote 4 because the schema
would not take null. Findings history was not rewritten.

`epoch=` and `seq=` stay on the error-log line. They were not
moved into the JSON.

## Part 2 — the suite asserts absence

`unknown-path-refused-undetermined` now requires
`absent: [declaredTier]`. A schema-valid 0.3.0 Attempt that
still writes `4` fails. Validation is not the property.

Both engines. The four unknown-path cells run that case.

## Part 3 — conformance by clause

`docs/SPEC.md` no longer says this engine implements 1.15.0.
Base: **1.15.0**. The claim is the clause list.

Implemented: C1–C13, including C10's absence-detectable sink
clause as later releases stated it. 52a claims C16; see
`docs/findings/52a.md`.

Emitted: `decision-record/0.2.0`, `attempt-record/0.3.0`,
`outcome-record/0.1.0`.

Not met:

- **C14** — not implemented.
- **C15** — partial. Enforcement-point half: no policy-service
  consult for suspension, no gateway denylist. Authorisation-server
  half: compiled-absence is the estate; this engine does not
  implement it.
- **`governed-set` as a titled identifier** — not claimed. C12's
  miss path is implemented; the later title is not. 52a: the
  artefact is built; see `docs/findings/52a.md`.
- **Requirement 6** — the operator's, not this engine's.

C8's line now says the pause is not agent suspension at the
authorisation server. Stating C15 as partial would otherwise
let C8 be read as the missing half.

This tree does not claim any later release as a whole.

## The pin

A version number is a claim that one document describes this
code. It held while the specification moved in whole versions
and the engine followed in whole versions. It stopped holding
the moment the engine implemented one clause of a later version
and declined the rest.

The pin did not fail loudly. It went on being a number that
looked right, while three tasks wrote notes explaining why it
was wrong. A claim that needs a footnote each time it is read
is not doing the work of a claim.

`VERSION` is the same shape: a scalar standing in for the list
of formats this tree actually vendors.

## Spec author

`docs/NEW-MATTER.md` is not in this repository. For the spec
author:

- Engine 52 emits `attempt-record/0.3.0` and omits
  `declaredTier` on an unassigned refusal. A 0.2.0 Attempt that
  invented `4` remains a 0.2.0 record.
- `epoch`/`seq` stayed on the sink line. Requirement 6 remains
  the operator's.
- Conformance is now a clause list. A version scalar cannot name
  a partial implementation. If the specification wants an
  implementation to state clauses rather than a release, that
  belongs there.
- `VERSION` 1.4.0 now vendors a later record type. Another
  scalar standing in for a list.

## Tests

`pytest -q`: **388 passed, 108 skipped.** Socket-blocked.

`pytest --live -q`: **490 passed, 6 skipped.** The four unknown-path
cells passed on Kong and on APISIX. A schema-valid 0.3.0 that
still wrote `declaredTier: 4` would have failed them.

## Observation

The pin was asked to do two jobs: name the document citations
resolve through, and claim what this code implements. Those
diverged the first time one clause moved and the rest did not.
Replacing the number with the list is the cheaper check. Worth
asking what else in this project is a scalar standing in for a
list.
